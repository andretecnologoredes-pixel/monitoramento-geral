Enviar firmware via MQTT

URL do firmware (.bin)
Use uma URL pública direta para o arquivo .bin.
Exemplo GitHub Raw: https://raw.githubusercontent.com/user/repo/main/fw.bin
Como funciona:
O painel envia o comando via MQTT WebSocket diretamente ao ESP32.

Comando enviado:
update https://url-do-firmware.bin

O ESP32 baixa o .bin da URL, grava e reinicia automaticamente.
O progresso aparece no log em tempo real via tópico torres/torre_SLUG/ota.

Requisitos:
• ESP32 deve estar online e conectado ao broker
• URL do .bin deve ser pública e acessível pelo ESP32
• Processo leva ~30–60s dependendo do tamanho do firmware
